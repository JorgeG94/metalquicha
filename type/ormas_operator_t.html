ormas_operator_t

type, private, extends(sigma_operator_t) :: ormas_operator_t

The restricted Hamiltonian, as something Davidson can multiply by

Holds what ormas_sigma_direct needs and nothing else. The vector it is handed is already flat, which is the reason the method had to be written that way: a restricted space has no rectangle to reshape into.
