type(json_file), public, pointer :: json => null()

Heap-allocated, and a pointer on purpose. json_file has a finaliser, so holding one by value would mean that growing the cache array – copy into a bigger array, move_alloc, old array finalised – destroys the parsed tree that the surviving copy still points at. Every basis loaded before the second one would go stale the moment the second arrived. Storing pointers means growth copies addresses and nothing is finalised.
