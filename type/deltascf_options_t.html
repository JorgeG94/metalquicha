deltascf_options_t

type, public, extends(scf_numerics_t) :: deltascf_options_t

Convergence settings for a second SCF run beside the first

The ions behind a Fukui analysis are their own SCF problem: a charged species in a basis chosen for a neutral one, so whatever converged the neutral is a default rather than a rule.

Inheritance happens at read time, not here. The reader seeds every inherited field from the resolved keywords.scf before it looks at the deck, so a key the deck does not name keeps the neutral’s value and a key it does name wins. Nothing here carries an “unset” sentinel because unset is spelled by the field holding the inherited value.
