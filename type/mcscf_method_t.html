procedure, public :: calc_gradient => mcscf_calc_gradient

  • private subroutine mcscf_calc_gradient(this, fragment, result)

    Not finite differences either, and that is a deliberate choice rather than an omission. A numerical CASSCF gradient is 6N converged orbital optimisations, each of which can land on a different active space – the orbitals that make up a CAS are identified by their character, and a displaced geometry can reorder them. The result is a gradient with discontinuities that look like noise, and nothing in the output would say which displacement had wandered. Better to refuse.
