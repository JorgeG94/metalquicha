libxc_role

private pure function libxc_role(name) result(role)

Which part of a functional a libxc name is: “x”, “c”, “xc”, “k” or “”

libxc spells every functional <family>_<role>_<label>, and the role is the first underscore-delimited segment that is one of those four. All 702 functionals in 7.1.2 follow it without exception, so this reads libxc’s own convention rather than keeping a list that could fall out of step with it. A name following no such convention returns “” and is left for libxc to reject in its own words.

   pure function libxc_role(name) result(role)
      !! Which part of a functional a libxc name is: "x", "c", "xc", "k" or ""
      !!
      !! libxc spells every functional `<family>_<role>_<label>`, and the role is
      !! the first underscore-delimited segment that is one of those four. All 702
      !! functionals in 7.1.2 follow it without exception, so this reads libxc's
      !! own convention rather than keeping a list that could fall out of step
      !! with it. A name following no such convention returns "" and is left for
      !! libxc to reject in its own words.
      character(len=*), intent(in) :: name
      character(len=2) :: role

      integer :: i, lo, n

      role = ""
      lo = 1
      n = len_trim(name)
      do i = 1, n + 1
         if (i <= n) then
            if (name(i:i) /= "_") cycle
         end if
         if (is_role(name(lo:i - 1))) then
            role = name(lo:i - 1)
            return
         end if
         lo = i + 1
      end do
   end function libxc_role
