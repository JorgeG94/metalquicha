cuest_backend_available

public pure function cuest_backend_available() result(available)

.false. – this build has no cuEST

Asked before a calculation starts, so a deck that asks for the GPU on a CPU-only build is refused while it is still a deck rather than after a fragment has been set up and handed to a bridge that computes nothing.
