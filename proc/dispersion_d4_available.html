dispersion_d4_available

public pure function dispersion_d4_available() result(available)

.false. – this build has no dftd4

Asked through mqc_dispersion_apply, so a deck naming keywords.dft.dispersion: "d4" on a build without the library is refused while it is still a deck, and by the version banner, so run_validation.py skips the gated cases rather than failing them.
