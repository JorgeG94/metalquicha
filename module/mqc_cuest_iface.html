integer, public, parameter :: BACKEND_AUTO = 0
integer, public, parameter :: BACKEND_CUEST = 1
integer, public, parameter :: BACKEND_CZT = 2
integer, public, parameter :: BACKEND_TERCO = 3

Which integral backend a deck asked for. auto is the default: cuEST when the build has it, the CPU path otherwise. The other two are requests, and a request that cannot be honoured is refused rather than quietly substituted.
