Both the SCF (mqc_libcint_rhf) and the FMO outer loop (mqc_libcint_fmo) report convergence as the same table: a title, a ruled column header, one row per iteration, and a footer saying whether and in how many steps it converged. The rows differ – the SCF carries DIIS depth and per-iteration timings, the FMO loop a single energy sum – so each caller writes its own row; the frame around it is identical and lives here.

Visibility is the caller’s, passed as show. This module prints through logger%info; the caller sets show from whatever logger level and rank guard the table belongs behind, so the SCF table and the FMO outer table can sit at different levels without this module knowing about either.
