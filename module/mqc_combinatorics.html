Provides pure combinatorial functions for generating molecular fragments including binomial coefficients, combinations, and fragment counting How many monomers a polymer row names Counterpoise subset key: chosen real, rest ghosted The same, for a row that may already carry ghosts A ghosted row: subtracted, never summed Real (non-ghosted) monomers in a row Binomial coefficient calculation Calculate total number of fragments Generate sequential monomer indices Generate all fragments up to max level Generate all combinations of size r Generate next combination in sequence Initialize combination to [1,2,…,k] Generate next combination (alternate interface) Debug utility to print combinations Calculate minimal distances for all fragments
