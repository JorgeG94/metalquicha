normalize_shell_coefficients normalized_coefficients

Normalizes contracted Gaussian shell coefficients.

Basis set files store coefficients for unnormalized primitives, but integral engines expect the contracted function to be normalized. This applies the standard two-stage normalization: a per-primitive factor, followed by an overall factor Q that normalizes the contracted function.

The convention matches the one cuEST’s own sample helpers use, so a basis normalized here reproduces the reference numbers exactly. Normalize one shell’s coefficients Normalize raw exponent/coefficient arrays
