run_terco_scf

The fpm build, and any CMake build with MQC_ENABLE_TERCO=OFF, compiles this. It reports that the backend was asked for and is not present rather than computing anything. The real implementation, compiled only by CMake with the backend, lives in backends/terco/backend/mqc_terco_bridge.f90 and provides the same module and the same run_terco_scf interface.
