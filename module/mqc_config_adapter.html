Converts a parsed input deck into the structures the driver and the methods read: driver_config_t and system_geometry_t. Minimal config for driver Convert log level string to integer Check for overlapping fragments (for testing) Refuse a counterpoise this expansion cannot honour Refuse a PIEDA request this expansion or driver cannot honour Refuse an interaction-energy run the reduced expansion cannot honour

Which molecule to use (for multi-molecule mode)
integer, intent(in), optional :: node_rank

Node-local MPI rank, for GPU binding
integer, intent(in), optional :: n_fragments

How many fragments the system actually has, when the config does not say. A settings-only document carries no molecules, so its own nfrag is 0, and the rule below would read that as “unfragmented” and compute the whole system as one piece – which converges and looks right. Pass the count from wherever the geometry came from.

Refuses a setting spelled in a way this program does not know. Optional, so the callers which cannot fail are unchanged; an unrecognised spelling then reaches run_geometry_optimization, which refuses it there.
