Same name, same procedures as the real backend, and both decline.

A stub rather than a preprocessor conditional at the call site, matching mqc_hdf5_checkpoint_stub and mqc_cuest_bridge_stub: the driver reads the same either way, and there is exactly one place where “this build cannot do that” is decided. crest_available is how a caller asks in advance, so the refusal can name the build option rather than failing somewhere less useful.
