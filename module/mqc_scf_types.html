Every SCF in the program – the supermolecular one, the deltaSCF ions behind a Fukui analysis, each rung of a basis-projection ladder, each fragment of an FMO run – is configured by the types here.

They live in src/scf rather than beside the deck types they are read from: src/scf depends on nothing but mqc_error, so mqc_config_types can name them without a cycle.
