Element tables for radial DFT quadrature

TREUTLER_XI_TABLE: the per-element radius parameter of the Treutler-Ahlrichs M4 mapping. H to Kr are the values optimised in the original paper [JCP 102, 346 (1995)]; heavier elements are the Psi4 values, which is also where PySCF takes them from. Index 0 is a ghost.

BRAGG_RADII_TABLE: Bragg-Slater atomic radii in Bohr, used to size the partition cells. Runs to Z=130, so nothing in the periodic table falls back to a default.

Generated by tools/dft_grid/gen_radial_fortran.py – do not edit by hand.
